# مشروع ليلى - نسخة أولية للموبايل

## محتويات المشروع
- `index.html`: واجهة ليلى والمحادثة التجريبية.
- `assets/layla.png`: صورة الشخصية.
- `manifest.webmanifest` و`service-worker.js`: إعدادات التثبيت والعمل الأساسي دون اتصال بعد أول تحميل.

## تشغيلها على Android
1. ارفع كل الملفات والمجلدات كما هي إلى مستودع GitHub جديد.
2. من إعدادات المستودع افتح Pages، واختر النشر من فرع `main` ومجلد `/ (root)`.
3. افتح رابط الموقع الناتج في Chrome على الهاتف.
4. من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إذا ظهر الخيار.

هذه نسخة واجهة تجريبية: تحفظ الرسائل محليًا على نفس المتصفح/الجهاز، وردود ليلى ثابتة وليست ذكاءً اصطناعيًا حقيقيًا. المحادثة الذكية والصوت يحتاجان لاحقًا إلى ربط خدمة AI وخدمة صوت، مع حماية مفاتيح API في خادم وسيط وعدم وضعها داخل ملفات التطبيق.
